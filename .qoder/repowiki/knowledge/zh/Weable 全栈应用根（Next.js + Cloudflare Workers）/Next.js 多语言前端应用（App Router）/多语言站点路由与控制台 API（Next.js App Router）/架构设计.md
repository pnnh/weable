该模块以 `src/app/[lang]/` 作为 Next.js App Router 的动态路由前缀，所有请求先经 `layout.tsx`：通过 `generateStaticParams` 预生成 `supportedLanguages` 中的语言路径，`generateMetadata` 按语言注入 SEO，并在默认布局中校验 `isValidLang(lang)`、设置 `<html lang>` 并挂载全局 CSS。

- 公开页面：`page.tsx`（首页）、`channels/`、`images/[id]/`、`games/[game]/`、`apps/`、`privacy/` 等子目录遵循文件系统路由约定，均为 async Server Component，直接解构 Promise 形式的 `params`/`searchParams` 获取参数。
- 数据访问集中在页面组件内：通过 `getDb()` 获取 Drizzle ORM 客户端，使用 `@/db/schema` 表定义配合 `eq/and/or/like/desc` 等谓词查询；需要用户态的页面通过 `getCurrentUser()` 鉴权。
- 控制台子域：`console/` 下既包含页面路由（`channels/`、`images/`、`profile/`），也包含 `api/` 下的 Route Handlers（`route.ts`），统一由 `_lib/gate.ts` 的 `requireConsoleUser` 守卫：非法语言返回 404，未登录返回 401 JSON。
- 国际化：所有 UI 文案通过 `t(l, key)` 从 `@/lib/i18n` 获取，禁止 JSX 硬编码文本；URL 构建统一通过 `new URLSearchParams()` 拼接 `q`/`page` 并以 `${l}` 前缀保持多语言路径一致。
- 依赖方向：页面 → `@/components/*`（SiteHeader/SiteFooter 等共享 UI）→ `@/lib/i18n`、`@/lib/language`、`@/lib/auth`、`@/db/*`；API route 仅依赖 `_lib/gate` 与数据库，不引用 React 组件。
