- 所有表的主键 id 字段统一通过 `text('id').primaryKey().$defaultFn(createId)` 定义，ID 由 `uuidv7()` 生成后经 `encodeUuidToBase58` 转为 Base58 字符串。
- 时间戳字段统一使用 `integer('created_at').notNull().$defaultFn(() => Date.now())` 模式，布尔字段使用 `integer(..., { mode: 'boolean' })` 配合默认值。
- 外键关系通过 Drizzle `references()` 声明级联策略（如 `onDelete: 'cascade'` / `'set null'`），并在 `relations()` 中成对定义双向关联。
- 数据库连接通过单一 `getDb()` 工厂函数获取，内部根据是否处于 Cloudflare 上下文自动切换 D1 与本地 SQLite，调用方无需感知后端差异。
