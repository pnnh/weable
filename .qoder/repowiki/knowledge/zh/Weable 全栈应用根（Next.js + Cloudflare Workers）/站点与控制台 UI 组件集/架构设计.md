模块为纯 React 组件目录，按功能域平铺组织：布局类（SiteHeader、SiteFooter）、频道相关（ChannelAvatar、ChannelAvatarUpload、ChannelDeleteSection、ChannelSearch）、图片管理（ImageUploadForm、ImagesTreeTable、ImageSearchBar、ImageDeleteSection、GameCoverPlaceholder、ImagesBatchToolbar、ImagesPagination）、内容展示（MarkdownContent、GameCard、GameGrid）以及用户交互（UserProfileClient）。组件分为两类：带 "use client" 指令的为客户端组件，负责状态管理、表单提交、路由跳转和 fetch API 调用；无该指令的（如 SiteHeader、GameGrid、MarkdownContent）作为服务器组件或纯展示组件使用。组件间通过 props 暴露配置，复杂表格/对话框内部通过局部 context（如 SelectionContext）在子树中共享选择状态。API 通信统一指向 /api/* 端点（如 /console/api/images），不依赖外部状态库。
