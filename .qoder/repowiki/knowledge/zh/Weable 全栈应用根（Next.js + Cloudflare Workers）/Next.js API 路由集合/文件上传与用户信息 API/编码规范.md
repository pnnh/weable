- 每个 Route Handler 都通过 `await getCurrentUser()` 在入口处获取当前用户上下文，未通过则后续逻辑不执行。
- 输入校验采用早期返回模式：对缺失参数、类型不符、大小超限等情况直接 `return NextResponse.json({ error: ... }, { status: 4xx })`。
- 文件上传统一从 `req.formData()` 中读取 `file` 字段，并通过 `Buffer.from(await file.arrayBuffer())` 转为 Buffer 后交给 storage 层保存。
- 数据库操作统一通过 `getDb()` 获取连接，使用 Drizzle ORM 的 `eq`/`and` 组合条件进行精确匹配。
- 静态常量（如允许的文件类型、最大尺寸、最大数量）在文件顶部以大写命名集中声明。
