该模块采用 Next.js App Router 的文件路由约定组织四个端点：根 route.ts 处理 GET /api/images（按 parentId 可选参数列出当前用户下的图片/目录，目录优先并按更新时间倒序）；[imageId]/route.ts 处理 PATCH 和 DELETE 单个资源的元数据与删除；[imageId]/file/route.ts 处理 GET /api/images/[imageId]/file 以二进制流返回实际文件内容；breadcrumb/route.ts 提供 GET /api/images/breadcrumb?parentId=... 向上回溯目录路径。所有路由均通过 @/lib/auth 的 getCurrentUser() 进行鉴权，通过 @/db/index 的 getDb() 获取 Drizzle 客户端操作 images 表，并通过 @/lib/storage 的 getStorage() 抽象层读写底层存储。每个路由显式声明 export const runtime = "nodejs" 以启用 Node.js 运行时。
