- 所有可分发资源（模板、脚本）均在 `speckit.manifest.json` 中以相对路径+SHA256 哈希登记，用于完整性校验。
- 扩展通过 `extension.yml` 声明 `schema_version`、`extension.*` 元数据与 `provides.commands` 列表，命令实现以 `commands/*.md` 文档形式暴露。
- 生命周期脚本在 `scripts/bash` 与 `scripts/python` 下保持同名成对存在（check_prerequisites、create_new_feature、setup_plan、setup_tasks），供不同执行环境选择。
- AI 集成通过 `integrations/<name>.manifest.json` 声明 `script` 与 `invoke_separator`，并在 `integration.json` 的 `integration_settings` 中按名称引用。
- 工作流在 `workflows/workflow-registry.json` 中注册后，对应 YAML 定义存放于 `workflows/<name>/workflow.yml`，形成 registry + 实现的分离布局。
- 特性目录命名遵循 `<编号>-<kebab-case>` 格式（如 `specs/008-remove-apps-privacy`），由 `feature.json` 的 `feature_directory` 指向当前活动特性。
