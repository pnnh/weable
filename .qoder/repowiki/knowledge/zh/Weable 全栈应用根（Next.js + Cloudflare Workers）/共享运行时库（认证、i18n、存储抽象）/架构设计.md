模块按职责划分为两个并列子目录，依赖方向单向向下，不互相引用：
- `src/lib/` 存放可复用的运行时逻辑：`auth.ts` 通过 Next.js `headers()`/`cookies()` 读取 Cloudflare Access JWT（`cf-access-jwt-assertion` / `CF_Authorization`），手动 Base64URL 解码 payload 后通过 Drizzle ORM (`getDb`/`users`) 写入并返回 `CurrentUser`；同时支持 `user_id`、`calieo_session` cookie 的开发模式假登录。
- `language.ts` 定义 `LangKey` 联合类型、支持语言列表及 `getTargetLang`/`isValidLang`，并使用 `accept-language` 注册受支持的语言集合。
- `i18n.ts` 静态导入 `@/locales/*.json` 构建 `Record<LangKey, LocaleMessages>`，暴露 `t(lang, key)` 函数并在缺失时回退到英文或键名。
- `storage.ts` 采用接口+适配器模式：先定义 `StorageAdapter`/`AvatarStorage` 接口，再实现 `LocalStorageAdapter`/`R2StorageAdapter` 与对应的 Avatar 包装类；通过模块级单例工厂 `getStorage()`/`getAvatarStorage()` 在检测到 Cloudflare R2 绑定 `IMAGES_BUCKET` 时选择 R2，否则回退到本地文件系统，未配置时抛出明确错误。
- `src/data/` 仅导出纯静态数据：`games.ts` 以 `GameData[]` 数组声明所有游戏的元信息、多语言名称/描述/特性/详情；`privacy.ts` 以 `Record<LangKey, PrivacyContent>` 结构导出各语言的隐私政策文本。该层只引用 `@/lib/language` 中的 `LangKey` 类型，不包含任何运行时副作用。
