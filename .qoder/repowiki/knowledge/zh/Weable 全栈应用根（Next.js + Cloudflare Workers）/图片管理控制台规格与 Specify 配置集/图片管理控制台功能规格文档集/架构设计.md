模块按功能迭代编号（001–004）划分独立子目录，每个子目录遵循统一模板：spec.md 为核心规格说明（含用户故事、FR-XXX 需求、SC-XXX 成功标准、Assumptions），plan.md/tasks.md 拆解实施计划与任务，data-model.md 定义数据模型，research.md 记录调研结论，quickstart.md 提供快速上手指引，checklists/requirements.md 用于需求核对，contracts/ 存放接口契约文档（如 get-images-and-breadcrumb.md、post-upload.md、patch-images-batch.md、get-images-list-search-pagination.md）。各规格之间相互独立，通过 Git 分支名（如 `001-image-directory-tree`）与项目代码关联，无跨规格的内部依赖；所有规格面向同一后端应用（部署在 Cloudflare Worker 上的图片管理控制台），共享 images/channel 等实体语义。
