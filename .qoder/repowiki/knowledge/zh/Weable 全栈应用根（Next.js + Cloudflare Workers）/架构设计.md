根目录作为单仓库入口，通过 pnpm-workspace.yaml 管理依赖，所有子模块共享同一份 TypeScript/Next.js 配置：tsconfig.json 的 `@/*` 路径别名使 frontend_app、api_endpoints、components、shared_libs、database_layer 之间以绝对路径互引；next.config.ts 启用 React Strict Mode 与 md/mdx 扩展，postcss.config.mjs + Tailwind v4 提供样式基础设施。运行时由 open-next.config.ts 与 wrangler.jsonc 驱动 OpenNext 将 Next.js App Router 应用编译为 Cloudflare Workers Edge 代码，database_layer 通过 drizzle.config.ts 管理 SQLite/D1 双后端迁移，shared_libs 暴露 StorageAdapter、i18n 工具与认证解析供其余子模块共同消费，形成「前端/组件 → API → shared_libs → database_layer」的分层调用链。
