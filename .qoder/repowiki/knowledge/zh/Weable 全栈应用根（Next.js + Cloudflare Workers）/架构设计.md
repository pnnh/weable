根目录作为 monorepo 入口，通过 pnpm-workspace.yaml 聚合各子模块；frontend_app 与 api_endpoints 基于 Next.js App Router 按文件系统约定组织页面与 REST 端点，二者共同消费 shared_libs 提供的认证解析、i18n 工具与 StorageAdapter 抽象，并通过 database_layer 的 Drizzle schema 访问数据。运行时由 @opennextjs/cloudflare 将 Next.js 应用编译为 .open-next/worker.js，再由 wrangler.jsonc 绑定 D1（DB）、R2（IMAGES_BUCKET/NEXT_INC_CACHE_R2_BUCKET）与静态资源（ASSETS），实现开发时 better-sqlite3 与生产时 D1/R2 的双后端切换；drizzle.config.ts 与 wrangler.jsonc 共用 migrations 目录完成迁移同步，形成从源码到边缘的统一流水线。
