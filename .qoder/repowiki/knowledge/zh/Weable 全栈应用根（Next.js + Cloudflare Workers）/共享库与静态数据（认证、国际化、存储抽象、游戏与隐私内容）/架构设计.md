本模块由两个并列子目录组成，职责清晰分离：
- `src/lib/` 存放可复用的运行时逻辑：`auth.ts` 通过 Next.js `headers()`/`cookies()` 读取 Cloudflare Access JWT（`cf-access-jwt-assertion` / `CF_Authorization`），解析后写入 `users` 表并返回 `CurrentUser`；`i18n.ts` 聚合 `@/locales/*.json` 并通过 `t(lang, key)` 提供按语言键查找的翻译函数；`language.ts` 使用 `accept-language` 库定义 `LangKey` 联合类型、支持的语言列表及 `getTargetLang`/`isValidLang` 工具；`storage.ts` 定义 `StorageAdapter` 与 `AvatarStorage` 两个接口，并提供 `LocalStorageAdapter`/`R2StorageAdapter` 与对应的 Avatar 包装类，通过 `getStorage()`/`getAvatarStorage()` 工厂在 Cloudflare R2 绑定存在时自动选择 R2，否则回退到本地文件系统。
- `src/data/` 仅包含纯静态数据导出：`games.ts` 以 `GameData[]` 数组形式声明所有游戏的元信息、多语言名称/描述/特性/详情；`privacy.ts` 以 `Record<LangKey, PrivacyContent>` 结构导出各语言的隐私政策文本。
依赖方向单向向下：`lib` 不依赖 `data`，`data` 仅引用 `@/lib/language` 中的 `LangKey` 类型，保证数据层无运行时副作用。
