该目录是 `.specify` 根下的静态配置与资源集合，按职责划分为多个子目录：
- 顶层 JSON/YAML 文件定义全局状态：`init-options.json` 记录初始化选项（AI 提供商、脚本语言、特性编号策略等），`integration.json` 维护已安装的 AI 集成（claude、qodercli）及其调用参数，`extensions.yml` 声明已启用扩展及钩子开关，`feature.json` 指向当前活跃特性目录。
- `integrations/` 存放各 AI 提供商的 manifest（如 `claude.manifest.json`），通过 SHA256 校验技能文件完整性。
- `workflows/` 包含工作流注册表 `workflow-registry.json` 以及具体工作流定义（如 `speckit/workflow.yml`）。
- `templates/` 提供 spec/plan/tasks/checklist/constitution 等 Markdown 模板。
- `scripts/` 同时提供 bash 与 python 双实现（同名文件成对出现，如 `create_new_feature.sh` 与 `create_new_feature.py`），供不同环境调用。
- `extensions/bug/` 是一个自包含扩展，通过 `extension.yml` 声明命令（`speckit.bug.assess|fix|test`）并引用 Markdown 形式的命令描述。
- `memory/` 存储带哈希校验的记忆模板，`bugs/` 以 slug 为目录名存放每个缺陷的 assessment 与 fix 报告。
依赖方向单向向外：本模块仅被 speckit CLI 读取，不反向依赖业务代码。
