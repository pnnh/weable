根目录作为单仓库入口，通过 pnpm-workspace.yaml 集中声明 better-sqlite3、esbuild、workerd 为仅构建期依赖；package.json 中的 scripts 提供 dev/build/start/db:migrate 等统一命令。所有子模块共享同一份 tsconfig.json，@/* 路径别名使 frontend_app、api_endpoints、components、shared_libs、database_layer 之间以绝对路径互引，形成「前端/组件 → API → shared_libs → database_layer」的分层调用链：frontend_app 与 components 消费 shared_libs 的 i18n、认证解析与 StorageAdapter；api_endpoints 在 Next.js App Router 下暴露 RESTful 端点，复用 shared_libs 的存储与数据库抽象；database_layer 通过 drizzle.config.ts 管理 SQLite/D1 双后端迁移；运行时由 open-next.config.ts 与 wrangler.jsonc 驱动 @opennextjs/cloudflare 将 Next.js 应用编译为 Cloudflare Workers Edge 代码，实现本地 better-sqlite3 与生产 D1 的无缝切换。
