本模块以 Next.js App Router 的文件系统路由为统一运行时，形成三层协作结构：根层 src/app/layout.tsx + page.tsx 提供全局样式与入口，并根据浏览器 Accept-Language 自动重定向到 [lang] 子路径；[lang]/ 作为所有公开页面、控制台（console）、游戏与静态内容的命名空间，内部再按 channels/images/profile/games 等功能域拆分页面组；API 路由同时存在于 src/app/api/（供公开页面调用）与 src/app/[lang]/console/api/（供控制台调用），两者目录结构与参数命名保持一致，使页面组件通过相对路径 /api/* 即可访问同一套后端能力。页面层与 API 层共享同一 App Router 运行时，无需额外配置即形成「页面 → fetch → route.ts」的单向数据流。
