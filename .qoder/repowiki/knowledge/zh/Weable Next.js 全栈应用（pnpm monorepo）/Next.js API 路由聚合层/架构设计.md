该模块是 Next.js App Router 下的 `/api` 命名空间，所有子目录通过 `route.ts` 暴露 HTTP 接口。
- 认证流程：`/api/auth/signin/calieo` 发起 OAuth PKCE 授权并写入短期 `oauth_state` cookie，`/api/auth/callback/calieo` 回调后校验 state、换取 token、查找或创建用户，最终写入 `calieo_session` 会话 cookie 并重定向至控制台。
- 资源访问：`images`、`upload`、`directories`、`user/avatar`、`channel/avatar` 等路由统一通过 `@/lib/storage` 的 `getStorage()` / `getAvatarStorage()` 抽象读写文件，避免直接耦合具体存储实现。
- 数据层：除认证回调外，其他路由统一通过 `@/db/index` 的 `getDb()` 访问 Drizzle ORM，使用 `@/db/schema` 中共享的 `images`、`createId` 等模型；目录与图片共用同一张 `images` 表，通过 `mimeType === 'directory'` 区分节点形成树形结构。
- 鉴权：业务路由（images/upload/user）统一调用 `getCurrentUser()` 获取当前用户，未登录即拒绝；公开资源（如 channel/avatar）则跳过鉴权直接读取存储。
- 错误处理：所有失败路径返回统一的 `{ error: string }` JSON 结构，并配合 400/404/409 等语义化状态码。
