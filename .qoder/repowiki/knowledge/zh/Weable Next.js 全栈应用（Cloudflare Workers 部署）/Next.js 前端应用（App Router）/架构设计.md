本模块以 Next.js App Router 为统一运行时，将三层职责按目录划分：
- 根布局层（src/app/layout.tsx + page.tsx）定义全局样式与入口，首页根据浏览器 Accept-Language 自动重定向至 [lang] 子路径。
- 多语言路由层（src/app/[lang]/...）作为所有公开页面、控制台（console）、游戏与静态内容的命名空间，内部再按 channels/images/profile/games 等功能域拆分页面组。
- API 路由层（src/app/api/ 与 src/app/[lang]/console/api/）采用 route.ts 文件，按资源域（user/images/channels/directories/upload）组织，供页面组件通过相对路径 /api/* 调用。
- 页面层与 API 层共享同一 App Router 运行时，无需额外配置即可形成「页面 → fetch → API」的单向数据流；console 下的 api/ 与根级 api/ 提供相同接口，分别服务于控制台与公开页面的不同访问场景。
