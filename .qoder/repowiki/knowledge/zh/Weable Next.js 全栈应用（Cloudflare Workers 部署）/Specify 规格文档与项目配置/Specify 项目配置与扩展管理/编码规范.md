- 每个可安装组件（集成、扩展、工作流）都通过独立的 manifest/extension.yml 声明版本、作者、许可证与依赖约束，并由注册表文件统一索引。
- 脚本类功能同时提供 bash 与 python 两套实现，文件名一一对应（如 `check_prerequisites.sh` 与 `check_prerequisites.py`），便于跨平台选择。
- AI 集成的文件完整性通过 SHA256 哈希在 manifest 中校验，确保技能文件未被篡改。
- Bug 报告以 slug 命名的独立目录组织，每个目录内固定包含 `assessment.md` 与 `fix.md` 两个文件。
- 模板与记忆文件采用 .json/.md 分离结构，并通过 sha256 字段标记来源（core/bundled）。
