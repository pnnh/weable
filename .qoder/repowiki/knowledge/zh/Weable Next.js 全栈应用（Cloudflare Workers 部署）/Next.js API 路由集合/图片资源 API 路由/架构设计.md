采用 Next.js App Router 的 Route Handlers 结构，按资源层级组织：
- `images/route.ts`：GET 列出当前用户下的图片或目录，支持通过 `parentId` 过滤子目录，使用 Drizzle ORM 对 images 表进行排序（目录优先、按 updatedAt 降序）。
- `images/[imageId]/route.ts`：PATCH 更新图片元数据（title/description/channelId/isPublished），DELETE 删除图片并同步清理存储。
- `images/[imageId]/file/route.ts`：GET 按 imageId 读取二进制文件内容，返回带 MIME 类型和长期缓存头。
- `images/breadcrumb/route.ts`：GET 根据 parentId 向上递归构建面包屑路径，最多迭代 20 层防止死循环。

所有路由统一通过 `getCurrentUser()` 鉴权、`getDb()` 获取数据库连接、`getStorage()` 访问底层存储，依赖方向单向指向 `@/lib/auth`、`@/db/index`、`@/db/schema`、`@/lib/storage`。每个 handler 显式声明 `runtime = "nodejs"`。
