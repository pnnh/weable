该模块是 Next.js App Router 下的 `/api` 命名空间，所有子目录（images、upload、directories、user、channel/avatar、channels）均通过 `route.ts` 暴露 HTTP 接口。
- 鉴权：所有路由统一调用 `@/lib/auth` 的 `getCurrentUser()` 获取当前用户，未登录即拒绝请求。
- 数据层：统一通过 `@/db/index` 的 `getDb()` 访问 Drizzle ORM，使用 `@/db/schema` 中共享的 `images`、`createId` 等模型。
- 存储层：文件读写统一走 `@/lib/storage` 的 `getStorage()` 抽象，避免直接耦合具体存储实现。
- 错误处理：所有失败路径返回统一的 `{ error: string }` JSON 结构，并配合 400/404/409 等语义化状态码。
- 资源模型：目录与图片共用同一张 `images` 表，通过 `mimeType === 'directory'` 区分节点，形成统一的树形资源结构。
