- 客户端组件在文件顶部使用 "use client" 指令，服务器组件则不包含该指令
- 组件通过 Props interface/type 定义类型，并使用 export default 导出函数式组件
- 多语言文案通过 labels 对象 prop 注入，而非硬编码字符串，便于 i18n 切换
- API 调用统一使用原生 fetch 请求 /api/* 端点，错误处理采用 try/catch 或 res.ok 判断
- 路由跳转使用 next/link 的 href 属性或 next/navigation 的 useRouter().push() 方法
- 样式统一使用 Tailwind CSS 原子类，避免内联 style 除动态计算场景（如缩进、尺寸）
