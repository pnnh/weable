- 多语言统一通过 `LangKey` 联合类型约束，所有语言相关对象（翻译映射、游戏条目、隐私内容）均以 `Record<LangKey, ...>` 或 `{ en, es, fr, 'de-DE', 'pt-PT', ja, zh, 'zh-TW' }` 形式组织。
- 存储实现采用接口+适配器模式：先定义 `StorageAdapter`/`AvatarStorage` 接口，再分别实现 `Local*` 与 `R2*` 适配器，并通过模块级单例工厂函数 `getStorage()`/`getAvatarStorage()` 按需实例化。
- 外部 I/O 模块（`node:fs/promises`、`node:path`、`accept-language`）采用动态 `import()` 引入，避免在编译期强制绑定 Node.js 环境，提升边缘环境兼容性。
- 输入校验集中通过辅助函数完成：`asNonEmptyString` 清理 JWT 字段、`assertSafeSegment` 校验路径片段防止目录穿越，并在出错时抛出带字段的 `Error`。
- 静态数据文件仅 `export` 常量，不包含任何业务逻辑，便于被多个页面/组件直接导入使用。
