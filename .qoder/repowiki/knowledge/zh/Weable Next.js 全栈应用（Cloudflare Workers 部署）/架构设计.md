根目录作为单仓库入口，通过 pnpm workspace 管理依赖，所有子模块（frontend_app、api_endpoints、components、shared_libs、database_layer、locales、specs_and_docs）共享同一份 TypeScript/Next.js 配置：tsconfig.json 使用 `@/*` 路径别名指向 src，next.config.ts 启用 React Strict Mode 与 md/mdx 页面扩展，postcss.config.mjs + tailwind v4 提供样式基础设施。运行时由 open-next.config.ts 与 wrangler.jsonc 驱动 OpenNext 将 Next.js 应用编译为 Cloudflare Workers 兼容的 Edge 代码；database_layer 通过 drizzle.config.ts 管理 SQLite/D1 双后端迁移，shared_libs 暴露 StorageAdapter、i18n 工具与认证解析供 frontend_app、components、api_endpoints 共同消费。开发流程通过 package.json scripts 统一启动：dev/build/start/db:migrate。
