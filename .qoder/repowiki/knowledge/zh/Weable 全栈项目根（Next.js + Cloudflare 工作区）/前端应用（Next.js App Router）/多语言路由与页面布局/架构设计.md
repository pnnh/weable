该模块是 Next.js App Router 下以 `[lang]` 动态段为核心的多语言根布局层：
- `layout.tsx` 作为统一布局，校验语言有效性（`isValidLang`）、生成 SEO Metadata（title/description/openGraph），并通过 `<html lang={lang}>` 设置文档语言；同时通过 `generateStaticParams` 预生成所有受支持语言的静态路径。
- 各业务页面（首页、频道列表/详情、图片详情、游戏详情、隐私页、apps 页）均位于 `[lang]/` 下的对应子目录中，遵循 Next.js 文件系统路由约定，每个页面组件均为异步 Server Component，直接读取 `params` 和 `searchParams`（Promise 形式）。
- 数据访问集中在页面组件内完成：使用 `getDb()` 获取 Drizzle ORM 客户端，配合 `@/db/schema` 中的表定义进行查询；需要用户态的页面（如 console）通过 `getCurrentUser()` 鉴权。
- 国际化通过 `@/lib/i18n` 的 `t(lang, key)` 函数在渲染时注入文案，所有 UI 文本均走此函数而非硬编码。
- 公共结构由 `SiteHeader`、`SiteFooter` 等共享组件复用，页面仅负责路由级组装与数据获取。
