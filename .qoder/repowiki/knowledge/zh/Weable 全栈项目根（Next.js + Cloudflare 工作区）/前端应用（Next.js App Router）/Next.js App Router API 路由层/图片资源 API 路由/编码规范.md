- 每个路由文件顶部统一声明 export const runtime = "nodejs" 以使用 Node.js 运行时。
- 所有写操作（PATCH/DELETE）先通过 getCurrentUser() 获取用户，再在 DB 查询中使用 eq(images.userId, user.id) 强制用户隔离，防止越权访问。
- 动态路由参数 [imageId] 统一通过 type Props = { params: Promise<{ imageId: string }> } 定义类型，并在函数内 await params 后使用正则 /^[a-zA-Z0-9_-]+$/ 校验合法性。
- 错误响应统一使用 NextResponse.json({ error: "..." }, { status: XXX }) 格式返回，状态码遵循 REST 规范（400/404/204）。
- 数据库查询统一通过 getDb() 获取实例，并使用 Drizzle 的 and、eq、isNull 等组合条件构造 WHERE 子句。
- 文件读写统一通过 getStorage() 获取存储适配器，避免直接依赖具体存储实现。
