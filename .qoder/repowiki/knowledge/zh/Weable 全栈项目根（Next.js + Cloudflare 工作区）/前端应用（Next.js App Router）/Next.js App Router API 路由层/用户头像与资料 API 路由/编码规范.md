- 每个路由文件顶部显式声明 `export const runtime = "nodejs"` 以启用 Node.js 运行时能力。
- 需要认证的接口统一通过 `await getCurrentUser()` 获取当前用户，未认证时由该函数抛出或返回空值。
- 对外部输入进行严格校验后再执行业务逻辑：头像类型限制在 ALLOWED_TYPES 白名单、大小不超过 MAX_SIZE、userId 匹配正则 `/^[a-zA-Z0-9_-]+$/`、profile 字段仅接受 string 或 null 并做 trim 和长度截断。
- 错误响应统一使用 `NextResponse.json({ error: "..." }, { status })` 格式，成功响应统一返回 `{ ok: true }`。
- 存储访问通过 `getAvatarStorage()` 工厂函数获取实例，避免直接依赖具体存储实现。
