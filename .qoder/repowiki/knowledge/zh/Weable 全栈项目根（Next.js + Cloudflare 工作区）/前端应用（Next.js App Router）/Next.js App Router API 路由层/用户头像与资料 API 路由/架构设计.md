模块遵循 Next.js App Router 的目录即路由约定：`avatar/route.ts` 提供 POST 接口用于当前用户上传头像，`avatar/[userId]/route.ts` 提供 GET 接口按 userId 读取头像二进制数据，`profile/route.ts` 提供 PATCH 接口更新当前用户的 nickname 和 bio 字段。每个路由文件都是独立的 handler，通过 `@/lib/auth` 的 `getCurrentUser` 获取认证用户，通过 `@/lib/storage` 的 `getAvatarStorage()` 抽象头像存储读写，通过 `@/db/index` 的 `getDb()` 配合 Drizzle ORM 的 `users` schema 执行数据库更新。所有路由统一声明 `runtime = "nodejs"`，错误响应均使用 `NextResponse.json` 返回 `{ error }` 结构，成功响应返回 `{ ok: true }`。
