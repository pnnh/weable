所有路由均位于 src/app/api/ 下，遵循 Next.js App Router 的文件路由约定：每个 route.ts 暴露 GET/POST/PATCH/DELETE 等函数处理对应 HTTP 方法。各子模块（images、user、upload、directories、channel/avatar）通过共享的基础设施协作：认证统一通过 @/lib/auth 的 getCurrentUser()；数据库访问统一通过 @/db/index 的 getDb() 和 Drizzle ORM；文件存储通过 @/lib/storage 抽象；ID 生成使用 @/db/schema 的 createId()。路由之间通过 images 表中的 parentId/mimeType 字段建立目录树关系，upload/directories 负责创建元数据，images/[imageId]/file 负责读取实际文件内容，形成「元数据 + 文件存储」分离的架构。
