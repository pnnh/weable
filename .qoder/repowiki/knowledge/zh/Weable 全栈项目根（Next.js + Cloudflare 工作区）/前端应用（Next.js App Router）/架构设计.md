本模块以 Next.js App Router 为核心，将页面路由、国际化与 API 路由统一在 src/app/ 下：
- 根布局（src/app/layout.tsx）定义全局样式与入口，首页根据浏览器 Accept-Language 自动重定向到 [lang] 子路径。
- [lang] 动态段作为所有公开页面、控制台（console）、游戏与静态内容的命名空间，内部再按功能划分 channels、images、profile 等页面组。
- api/ 目录采用 RESTful 风格的路由文件（route.ts），按资源域拆分 user、images、channels、upload、directories 等子模块，供页面组件通过 fetch 调用。
- 页面层与 API 层共享同一 App Router 运行时，无需额外配置即可通过相对路径访问 /api/* 接口，形成「页面 → API」的单向数据流。
