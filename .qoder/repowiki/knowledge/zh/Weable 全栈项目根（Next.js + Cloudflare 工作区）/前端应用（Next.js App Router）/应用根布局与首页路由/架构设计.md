该模块是 Next.js App Router 的顶层入口，由三个文件组成：`layout.tsx` 作为 RootLayout 组件仅透传 `children`，不附加任何 HTML/Head 包裹；`page.tsx` 作为根路由 `/` 的异步页面，通过 `next/headers` 读取 `Accept-Language` 请求头，调用 `@/lib/language` 中的 `getTargetLang` 与 `defaultLanguage` 确定目标语言后使用 `next/navigation` 的 `redirect` 跳转到 `/${lang}/`；`globals.css` 通过 `@import "tailwindcss"` 引入 Tailwind v4，使用 CSS 变量定义明暗主题色并在 `@theme inline` 中暴露给 Tailwind 使用，同时为 `body` 设置默认字体栈。依赖方向单向向下：页面层依赖 `@/lib/language`，样式层无 JS 依赖。
