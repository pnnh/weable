模块由三个核心文件组成：
- `schema.ts`：使用 `drizzle-orm/sqlite-core` 声明式定义 `users`、`channels`、`images` 三张表及其关系（`relations`），并通过 `uuidv7` + `bs58` 生成 Base58 编码的 ID，作为所有表的 `$defaultFn`。
- `index.ts`：暴露 `getDb()` 工厂函数，优先通过 `@opennextjs/cloudflare` 获取 D1 binding 构建 Drizzle 实例；若不在 Cloudflare 上下文则回退到基于 `better-sqlite3` 的本地 SQLite 文件（路径由 `DB_PATH` 环境变量控制，默认 `./.data/weable.db`），并自动确保目录存在。
- `migrate.ts`：独立的 CLI 入口，直接通过 `drizzle-orm/better-sqlite3/migrator` 对 `./migrations` 目录执行迁移，支持以 Node 脚本直接运行。

依赖方向单向：`index.ts` → `schema.ts`；`migrate.ts` 独立于运行时 db 实例，仅依赖 Drizzle 迁移器。迁移元数据由 `migrations/meta/_journal.json` 维护，SQL 文件按序号命名，使用 `--> statement-breakpoint` 分隔多条语句。
