模块由三个独立的 Route Handler 组成，均遵循 Next.js App Router 的文件路由约定：`/api/upload/route.ts` 处理 POST 多文件图片上传并持久化到对象存储；`/api/user/avatar/route.ts` 处理当前登录用户的头像上传，`/api/user/avatar/[userId]/route.ts` 暴露 GET 接口按 userId 读取头像；`/api/user/profile/route.ts` 处理 PATCH 请求部分更新用户资料。所有路由统一通过 `@/lib/auth` 的 `getCurrentUser()` 进行鉴权，通过 `@/db/index` 的 `getDb()` 获取 Drizzle ORM 客户端操作数据库，通过 `@/lib/storage` 的 `getStorage()` / `getAvatarStorage()` 抽象底层对象存储读写，形成「路由层 → 认证/存储/数据库」的单向依赖结构。
