- 每个 route handler 都显式导出 `runtime = "nodejs"` 以启用 Node.js 运行时特性。
- 动态路由参数统一通过 `type Props = { params: Promise<{ ... }> }` 声明并在 async 函数中 `await params` 解构。
- 所有对外暴露的 imageId 参数均使用 `/^[a-zA-Z0-9_-]+$/` 正则校验，非法时返回 400 错误。
- 数据访问一律先通过 `getCurrentUser()` 获取用户，再在 WHERE 条件中拼接 `eq(images.userId, user.id)` 保证用户隔离。
- 错误响应统一返回 `{ error: string }` 结构的 JSON，并通过 `NextResponse.json(..., { status })` 设置 HTTP 状态码。
- Drizzle ORM 查询使用 `and`/`eq`/`isNull`/`sql` 等函数组合条件，避免字符串拼接 SQL。
