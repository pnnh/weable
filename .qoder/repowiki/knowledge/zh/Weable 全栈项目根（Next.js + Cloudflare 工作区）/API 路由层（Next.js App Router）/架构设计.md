该模块是 Next.js App Router 下的 `/api` 命名空间，按功能拆分为 `images/`、`upload/`、`directories/`、`user/`、`channel/avatar/`、`channels/[channelId]/` 等子目录，每个目录对应一个或多个 `route.ts` 文件。
- 所有路由统一通过 `@/lib/auth` 的 `getCurrentUser()` 进行鉴权，通过 `@/db/index` 的 `getDb()` 访问 Drizzle ORM 数据库，通过 `@/db/schema` 中的 `images`、`createId` 等共享模型。
- 文件读写统一走 `@/lib/storage` 的 `getStorage()` 抽象，避免直接耦合具体存储实现。
- 错误处理采用一致的 JSON 响应格式 `{ error: string }` 并返回相应 HTTP 状态码（400/404/409）。
- 目录与图片共用同一张 `images` 表，通过 `mimeType === 'directory'` 区分目录节点，形成统一的树形资源模型。
