- 所有路由通过 `export const runtime = "nodejs"` 声明 Node.js 运行时以支持文件流与文件系统操作
- 请求体统一使用 `req.json()` 或 `req.formData()` 解析，失败时返回 `{ error }` 与 400 状态码
- 鉴权统一调用 `await getCurrentUser()` 获取当前用户，未登录即拒绝请求
- 数据库操作统一通过 `getDb()` 获取连接，并使用 `and`、`eq`、`isNull` 等 Drizzle 条件组合
- 文件上传统一限制 MIME 前缀为 `image/`、单文件最大 5MB、批量最多 50 个，并通过 `createId()` 生成唯一 ID
- 错误响应统一返回 `{ error: string }` 结构，并按语义使用 400/404/409 等状态码
