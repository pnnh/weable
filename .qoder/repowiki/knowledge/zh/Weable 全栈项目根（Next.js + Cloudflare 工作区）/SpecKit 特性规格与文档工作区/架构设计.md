该模块由两大部分组成：
- `.specify/` 是 SpecKit 引擎的配置与扩展层：`feature.json` 指向当前活跃特性目录；`integration.json` 声明默认集成（claude/qodercli）及调用约定；`extensions.yml` 启用 bug triage 扩展；`workflows/speckit/workflow.yml` 定义 `specify → plan → tasks → implement` 四步流水线及 review gate；`templates/` 提供 spec/plan/tasks/checklist/constitution 等 Markdown 模板；`scripts/{bash,python}/` 提供 `create-new-feature.sh`、`setup-plan.sh`、`setup-tasks.sh` 等脚手架脚本，以及对应的 Python 实现；`memory/`、`bugs/`、`integrations/` 分别存放宪法模板、缺陷评估/修复记录与集成 manifest。
- `specs/<NNN>-<feature>/` 是每个特性的独立文档目录，遵循统一结构：`spec.md`（用户故事+需求+成功标准）、`plan.md`、`research.md`、`data-model.md`、`quickstart.md`、`tasks.md`、`checklists/requirements.md`，以及可选的 `contracts/` API 契约文件。
依赖方向单向：脚本与模板驱动生成 specs 下的文档，specs 文档再被 speckit 命令消费以生成代码，本模块不包含任何可执行源码。
