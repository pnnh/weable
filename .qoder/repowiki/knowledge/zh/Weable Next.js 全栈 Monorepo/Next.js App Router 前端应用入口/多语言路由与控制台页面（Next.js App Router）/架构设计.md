模块以 `src/app/[lang]/` 作为 Next.js App Router 的动态路由前缀，内部按功能划分为三层：
- 顶层布局层：`layout.tsx` 通过 `generateStaticParams` 基于 `supportedLanguages` 预生成所有语言路径，`generateMetadata` 按语言注入 SEO，并在默认布局中校验 `isValidLang(lang)`、设置 `<html lang>` 并挂载全局 CSS。
- 公开页面层：`page.tsx`、`channels/`、`images/[id]/`、`account/signin|signout/` 等均为 async Server Component，直接解构 Promise 形式的 `params`/`searchParams` 获取参数，并通过 `@/components/SiteHeader`、`SiteFooter` 组合页面骨架。
- 控制台子域：`console/` 下既包含页面路由（`channels/`、`images/`、`profile/`），也包含 `api/` 下的 Route Handlers（`route.ts`），统一由 `_lib/gate.ts` 的 `requireConsoleUser` 守卫：非法语言返回 404，未登录返回 401 JSON；API 仅依赖数据库与 auth，不引用 React 组件。
依赖方向单向收敛：页面 → `@/components/*` → `@/lib/i18n`、`@/lib/language`、`@/lib/auth`、`@/db/*`；Server Actions（如 `account/signin/actions.ts`）独立处理表单提交并写入 cookie 后 redirect。
