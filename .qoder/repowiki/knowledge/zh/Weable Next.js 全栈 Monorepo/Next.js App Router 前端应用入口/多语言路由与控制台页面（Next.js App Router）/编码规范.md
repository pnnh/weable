- 所有页面组件均为 async Server Component，通过解构 `params` 和 `searchParams`（Promise 形式）获取路由参数与查询参数。
- 每个页面开头统一执行 `if (!isValidLang(lang)) notFound();` 并将 `lang` 断言为 `LangKey`，确保语言类型安全。
- 页面文案一律通过 `t(l, key)` 从 `@/lib/i18n` 获取，禁止在 JSX 中硬编码显示文本。
- 分页页面采用本地 `PAGE_SIZE` 常量，并使用 `Promise.all` 并行执行计数查询与分页查询，再计算 `totalPages` 与当前页码。
- URL 构建统一通过 `new URLSearchParams()` 拼接 `q` 与 `page` 参数，并以 `${l}` 前缀保持多语言路径一致性。
- SEO 元信息通过 `generateMetadata` 导出函数声明，根据当前语言与上下文动态生成 title、description 与 openGraph 字段。
- 控制台 API route 统一调用 `_lib/gate.ts` 的 `requireConsoleUser` 进行语言校验与登录门禁，非法语言返回 404，未登录返回 401 JSON。
