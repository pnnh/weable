本模块按 Next.js App Router 约定划分三层：src/app/layout.tsx + page.tsx 作为根层提供全局样式与首页，并根据浏览器 Accept-Language 自动重定向到 [lang] 子路径；src/app/[lang]/ 作为所有公开页面、控制台（console）与账户页面的命名空间，内部按 channels/images/profile/games 等功能域拆分；API 路由同时存在于 src/app/api/（供公开页面调用）与 src/app/[lang]/console/api/（供控制台调用），两者目录结构与参数命名保持一致，使页面组件通过相对路径 /api/* 即可访问同一套后端能力。页面层与 API 层共享同一 App Router 运行时，形成「页面 → fetch → route.ts」的单向数据流，无需额外配置即可实现前后端同构。
