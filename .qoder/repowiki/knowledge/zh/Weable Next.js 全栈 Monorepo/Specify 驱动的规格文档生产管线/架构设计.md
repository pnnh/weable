本模块由两层协作构成：.specify/ 是生产管线（templates/ 定义目录骨架、workflows/ 编排生成步骤、extensions.yml/integration.json/feature.json 注册扩展与集成、scripts/ 提供辅助命令），specs/<n>-*/ 是产出物（每个特性目录遵循 spec.md / data-model.md / plan.md / tasks.md / quickstart.md / research.md / checklists/requirements.md / contracts/* 的固定结构）。两者通过 Specify CLI 耦合——开发者在 .specify 中配置项目元数据与模板，CLI 据此生成 specs 下的特性目录；后续实现阶段消费这些文件，其中 contracts/*.md 作为特性间的契约边界供代码层引用。编号顺序体现特性演进次序，形成从基础设施到产物的单向依赖。
