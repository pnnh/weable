- 客户端组件在文件首行使用 "use client" 指令，服务器组件则不包含该指令
- 组件通过 TypeScript Props interface/type 定义类型，并以 export default 导出函数式组件
- 多语言文案通过 labels 对象 prop 注入（如 BatchChannelDialog、ImagesTreeTable），而非硬编码字符串
- API 调用统一使用原生 fetch 请求 /api/* 端点，错误处理采用 try/catch 配合 res.ok 判断并回退到 labels.operationFailed
- 路由跳转使用 next/link 的 href 属性或 next/navigation 的 useRouter().push() 方法，路径遵循 /:lang/... 前缀约定
- 样式统一使用 Tailwind CSS 原子类，仅对动态计算值（如缩进、尺寸）使用内联 style
