# Quickstart：验证控制台图片批量上传与树形列表优化

## 1. 前置条件

- Node.js 与 pnpm 已安装。
- 已完成依赖安装：

```bash
pnpm install
```

- 数据库迁移已执行：

```bash
pnpm run db:migrate
```

- 准备测试账号并可登录控制台。
- 准备测试文件：
  - 3 张小于 5 MB 的图片（用于成功场景）。
  - 1 张大于 5 MB 的图片（用于失败场景）。
  - 可选：准备 51 张图片（用于数量上限场景）。

## 2. 启动应用

```bash
pnpm dev
```

访问：`http://localhost:7600/en/console/images`

## 3. 核心验证场景

### 场景 A：根目录批量上传成功并返回列表

1. 进入 `/en/console/images`（不带 `parentId`）。
2. 打开上传入口，一次选择 2~3 张小图并提交。
3. 预期：
   - 上传成功后停留在 `/en/console/images`。
   - 页面刷新后可看到新增图片。
   - 不跳转至单图编辑页。

### 场景 B：子目录批量上传成功并保留 parentId

1. 在 `/en/console/images` 中进入任意目录，确保 URL 为 `/en/console/images?parentId=<目录ID>`。
2. 发起批量上传（2~3 张小图）。
3. 预期：
   - 上传成功后仍在 `/en/console/images?parentId=<同一目录ID>`。
   - 刷新后当前目录列表出现新增图片。

### 场景 C：超数量限制拦截

1. 在上传入口一次选择 51 张图片。
2. 提交上传。
3. 预期：
   - 提交被阻止。
   - 出现“最多 50 张”的错误提示。

### 场景 D：超大小限制拦截

1. 在上传入口选择包含至少一张 >5 MB 的图片。
2. 提交上传。
3. 预期：
   - 提交被阻止。
   - 出现“单张不超过 5 MB”的错误提示。

### 场景 E：树形展开缩进与对齐稳定

1. 准备至少 2 层目录结构。
2. 在 `/en/console/images` 连续展开父目录与子目录。
3. 预期：
   - 子级以内联树形表格显示并按层级缩进。
   - 同层级行在展开前后无横向跳动。
   - 左侧三角控件区域宽高占位固定。

- 空目录展开与加载失败提示不破坏列表对齐。
