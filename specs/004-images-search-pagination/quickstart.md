# Quickstart: 控制台图片列表关键词搜索与分页 —— 验证指南

**Feature**: `004-images-search-pagination` | 接口契约见 [contracts/get-images-list-search-pagination.md](./contracts/get-images-list-search-pagination.md)，数据模型见 [data-model.md](./data-model.md)

## 前置条件

1. 已安装依赖并启动本地开发服务：

```bash
pnpm install
pnpm dev
```

2. 已登录控制台（本地以 `.data/weable.db` 为数据源）。
3. 准备数据（可经页面操作完成）：
   - 根目录下 **≥ 45 个直接条目**（图片与目录混合，用于分页场景）
   - 其中若干图片标题包含共同关键词（如 `logo`），至少 1 张已关联频道、至少 1 张未关联频道
   - 至少 1 个含子条目的目录（用于展开状态保持场景）

## 验证场景

### 场景 1：关键词搜索（User Story 1）

1. 打开 `/en/console/images`，确认搜索框与"设置发布状态 / 设置频道"按钮位于同一行。
2. 输入 `logo` 并提交（Enter 或按钮）：
   - **预期**：仅显示当前目录下标题含 `logo` 的图片与目录；地址栏出现 `?q=logo`；分页信息按过滤后数量更新。
3. 清空搜索框并提交：**预期** 恢复全部直接条目，回到第 1 页。
4. 输入不存在的关键词：**预期** 展示"无匹配结果"提示，搜索框仍可用。
5. 注入试探：输入 `%' OR '1'='1` 与 `logo_`：
   - **预期** 按普通文本匹配（前者无结果或仅匹配含该字面量的标题；后者只匹配标题中字面含 `logo_` 的条目，`_` 不作通配符），页面无报错。
6. 大小写：输入 `LOGO`：**预期** 与 `logo` 结果一致（ASCII 标题）。

### 场景 2：分页浏览（User Story 2）

1. 打开含 ≥45 个直接条目的目录：**预期** 仅显示 20 条；分页控件显示共 3 页、当前页高亮、"上一页"禁用。
2. 点击"下一页"与页码"3"：**预期** 内容切换、URL `page` 参数同步；最后一页"下一页"禁用。
3. 组合搜索：先搜索再翻页至第 2 页：**预期** URL 同时含 `q` 与 `page`，结果仍在搜索条件内。
4. 复制第 3 步的完整地址到新标签页打开：**预期** 还原相同视图（SC-005）。
5. 非法参数手测：将 URL `page` 改为 `0`、`abc`、`999`：**预期** 分别回退第 1 页、第 1 页、空结果页，无报错。
6. 点击面包屑或某目录进入新目录：**预期** `q`/`page` 消失，新目录从第 1 页无搜索条件开始。
7. 条目 ≤20 的目录：**预期** 不显示分页控件。

### 场景 3：新增列（User Story 3）

1. 查看已关联频道的图片行：**预期** 频道列显示频道名称；未关联的图片与目录行该列为空。
2. 查看文件大小列：**预期** <1MB 显示 KB、≥1MB 显示 MB；目录行为空。
3. 进入图片详情页修改后返回列表：**预期** 修改时间列反映最新时间。
4. 展开某目录：**预期** 子行同样显示频道名称/文件大小/修改时间（数据来自展开接口）。

### 场景 4：批量操作后就地刷新（User Story 4）

1. 展开一个子目录（保持展开），勾选当前页若干图片。
2. 执行"设置频道"选择某频道并确认：
   - **预期** 受影响图片的频道列即时更新；页面**无整页刷新**（浏览器加载指示器不出现）；已展开目录**保持展开**且子行可见；选择集被清空。
3. 重复以"设置发布状态"验证发布徽章同样即时更新。
4. 在搜索条件下执行批量操作：**预期** 刷新后仍停留在该搜索条件与当前页。

### 场景 5：回归（树展开与既有功能）

1. 点击目录左侧三角箭头展开/收起：**预期** 行为与现有一致（懒加载子级），不受搜索/分页影响。
2. 上传、新建目录、单图编辑/删除路径抽查：**预期** 无回归。
3. 切换语言（如 `/zh/console/images`）：**预期** 搜索框、分页控件、新列头、空结果提示均为对应语言文案。

### 场景 6：接口级抽查（可选，curl/浏览器直访）

- 未登录访问 `/en/console/api/images?pageSize=20`：**预期** `401 {"error":"Unauthorized"}`。
- 登录后 `/en/console/api/images?pageSize=20&page=2`：**预期** 返回 `items`（≤20）+ `total`/`page`/`pageSize`。
- 登录后 `/en/console/api/images?parentId=<某目录>`（不传 `pageSize`）：**预期** 全量返回、无分页字段（树展开兼容）。

## 完成标准

上述 6 个场景全部符合预期，且 `pnpm build` 无类型错误。
