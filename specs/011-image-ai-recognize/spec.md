# Feature Specification: 图片编辑页本地 AI 识别填表

**Feature Branch**: `011-image-ai-recognize`

**Created**: 2026-08-13

**Status**: Draft

**Input**: User description: "我想在/[lang]/console/images/[id]页面，图片的下方，信息表单的上方增加一个工具栏。在工具栏最左侧增加一个代表“AI识别”的图标。点击后，调用浏览器内置 AI 来进行图片内容识别，然后自动填写下方表单中图片 Title 和 Description 信息（覆盖已有值，只更新字段不要保存提交）。点击前先弹出确认。确认后按钮进入加载中且不可点击，直到成功、失败或超时。失败时可悬停查看原因并点击重试。浏览器不支持时按钮禁用并提示切换至 Chrome 或 Edge。"

## Clarifications

### Session 2026-08-13

- Q: 确认框是否允许选择回填语言？ → A: 二次确认中必须提供语言下拉框，选项与站点支持的英 / 西 / 中（`en` / `es` / `zh`）一致；默认值为当前 URL `[lang]`；确认后按所选目标语言填写 Title 与 Description。
- Q: 识别失败后用户再点「AI 识别」，还要不要弹出带语言下拉的确认框？ → A: 失败重试不弹确认，沿用上次确认的目标语言。

## 用户场景与测试 *(mandatory)*

### 用户故事 1 — 在图片与表单之间使用工具栏发起识别 (Priority: P1)

已登录用户打开某张图片的编辑页，在图片预览下方、信息表单上方看到一条工具栏。工具栏最左侧是「AI 识别」操作（图标表达识别含义）。用户点击后先看到确认说明：该功能使用浏览器本地能力识别当前图片，成功后会覆盖下方表单的标题与描述，但不会自动保存。确认框内含目标语言下拉框（英 / 西 / 中），默认与当前 URL `[lang]` 一致。用户确认后开始识别；取消则关闭说明，表单不变。

**Why this priority**: 这是功能入口与安全确认。没有工具栏和二次确认，后续识别、回填、失败重试都无法发生；覆盖已有文案属于破坏性编辑，必须先告知。

**Independent Test**: 打开任一已有图片编辑页，确认工具栏出现在预览与表单之间；点击图标弹出确认；点取消后标题/描述保持原值且未提交。

**验收场景**:

1. **Given** 用户打开 `/[lang]/console/images/[id]` 已有图片编辑页（非新建上传页），**When** 页面加载完成，**Then** 图片预览下方、信息表单上方出现一条工具栏，「AI 识别」操作位于工具栏最左侧。
2. **Given** 当前浏览器支持本地图像识别，**When** 用户点击「AI 识别」，**Then** 弹出确认，明确说明：识别在本机浏览器完成、成功后将覆盖标题与描述、不会自动保存；确认框含目标语言下拉框（选项与站点 `en` / `es` / `zh` 一致），默认选中当前 URL 的 `[lang]`；并提供执行与取消。
3. **Given** 确认已打开且页面语言为 `zh`，**When** 用户将目标语言改为 `en` 后选择执行，**Then** 确认关闭，识别按英语生成标题与描述。
4. **Given** 确认已打开，**When** 用户选择取消，**Then** 确认关闭，标题与描述保持原值，未发生保存或跳转；下拉框的临时选择不保留。
5. **Given** 确认已打开且用户未改语言，**When** 用户选择执行，**Then** 确认关闭，识别按当前页面语言生成标题与描述，「AI 识别」进入加载中且不可再次点击。

---

### 用户故事 2 — 识别成功后只回填标题与描述 (Priority: P1)

用户确认执行后，系统用当前预览图做本地内容识别，按确认框所选目标语言生成标题与描述，写入下方表单对应字段并覆盖原值。频道、发布状态等其它字段不变。页面不自动保存、不跳转，用户仍可继续编辑后手动保存。页面 UI 文案仍随 URL `[lang]`，不因本次目标语言选择而切换站点语言。

**Why this priority**: 减少手工写标题/描述的成本是本功能的核心价值；「只改字段、不提交」避免误发布或误覆盖已入库内容。

**Independent Test**: 在支持本地识别的环境中确认执行，验证标题与描述被新文案覆盖，其它字段不变，网络中无保存请求，用户仍可再改并手动保存。

**验收场景**:

1. **Given** 识别成功并返回标题与描述，**When** 识别结束，**Then** 表单标题与描述被新值覆盖（含原先已有内容），「AI 识别」恢复为可点击的就绪状态。
2. **Given** 识别成功，**When** 查看表单，**Then** 频道、是否发布等其它字段保持识别前的值。
3. **Given** 识别成功，**When** 观察页面，**Then** 不出现自动保存、不跳转回列表，用户可继续编辑后手动点保存。
4. **Given** 用户在确认框选择了目标语言 L（`en` / `es` / `zh` 之一），**When** 识别成功，**Then** 回填的标题与描述使用语言 L（或其自然变体），即使 L 与当前 URL `[lang]` 不同。

---

### 用户故事 3 — 不支持时禁用并引导更换浏览器 (Priority: P1)

用户进入编辑页时，系统先检测当前浏览器是否具备本地图像识别能力。不具备时「AI 识别」禁用；鼠标悬停说明需改用目前支持较完整的浏览器（Chrome 或 Edge）。禁用状态下点击无效果、不弹确认、不发起识别。

**Why this priority**: 目前仅少数浏览器具备完整本地识别能力。若不做能力检测，用户会在多数浏览器里点了却失败，体验差且难排查。

**Independent Test**: 在不具备该能力的浏览器（或模拟不具备）打开编辑页，确认按钮禁用，悬停可见更换 Chrome/Edge 的说明，点击无确认、无识别。

**验收场景**:

1. **Given** 当前浏览器不具备本地图像识别能力，**When** 页面完成能力检测，**Then** 「AI 识别」为禁用，外观与可点击状态可区分。
2. **Given** 按钮已禁用，**When** 用户将指针悬停在该操作上，**Then** 提示需切换至 Chrome 或 Edge 等支持该能力的浏览器。
3. **Given** 按钮已禁用，**When** 用户点击该操作，**Then** 不弹出确认，不开始识别，表单不变。
4. **Given** 当前浏览器具备该能力，**When** 页面完成能力检测，**Then** 「AI 识别」可点击（无进行中任务时）。

---

### 用户故事 4 — 加载、超时、失败与重试 (Priority: P2)

用户确认执行后，按钮保持加载中且不可点，直到成功、失败或超时。超时与失败都进入失败态：悬停可见原因，点击可重试。失败重试不再弹确认，并沿用上次确认的目标语言。加载期间不能并行发起第二次识别。成功回到就绪后再点「AI 识别」，会再次弹出确认（下拉默认仍为当前 URL `[lang]`）。

**Why this priority**: 大图或本机模型未就绪时可能较慢；没有超时与失败反馈，用户会以为卡住。可恢复的失败比静默失败更安全。

**Independent Test**: 分别模拟成功、超时、失败；验证加载中不可点、失败可悬停见原因、点击可再跑、加载中无法并行第二次识别。

**验收场景**:

1. **Given** 用户已确认执行，**When** 识别尚未结束，**Then** 按钮显示加载中、不可点击，且无法并行发起另一次识别。
2. **Given** 识别在时限内成功，**When** 结束，**Then** 按钮回到就绪，表单按用户故事 2 回填。
3. **Given** 识别超过时限仍未完成，**When** 到达时限，**Then** 本次识别停止，按钮进入失败态，悬停说明因超时未完成。
4. **Given** 识别出错（能力中途不可用、无法读取当前图、结果无法使用等），**When** 结束，**Then** 按钮进入失败态，悬停可见简要原因，表单保持识别前的标题与描述。
5. **Given** 按钮处于失败态且上次确认的目标语言为 `en`，**When** 用户点击，**Then** 不弹出确认，立即按英语再次识别，按钮回到加载中。
6. **Given** 重试再次失败或超时，**When** 结束，**Then** 仍为失败态，悬停原因更新为最近一次；再次点击仍沿用同一目标语言。
7. **Given** 识别已成功、按钮回到就绪，**When** 用户再次点击「AI 识别」，**Then** 重新弹出带语言下拉的确认框（默认当前 URL `[lang]`），不得沿用失败重试的免确认路径。

---

### 边界情况

- 打开的是新建上传页（`/console/images/new`）或目录：本功能不出现，行为与现网一致。
- 图片预览尚未可用或无法读取：识别失败，表单不改，悬停说明无法读取当前图片。
- 识别结束但标题为空或仅空白：视为失败，不写入空标题（标题为必填），描述也不部分写入，避免半更新。
- 识别结束但描述为空、标题有效：允许写入（描述本就可空），标题覆盖为新值，描述覆盖为空。
- 用户在加载中离开页面或关闭标签：不在后台继续改库；再次进入编辑页时表单为服务器上的原值，按钮为就绪或按能力检测禁用。
- 用户在确认未关时刷新或后退：不开始识别，表单为原值。
- 本机模型首次使用需要额外等待：计入加载中；若在就绪等待时限内仍不能开始识别，按失败处理并说明本地能力未就绪。
- 连续快速点击：确认弹出前以一次为准；加载中忽略点击。
- 用户先手改标题/描述再点识别并确认：按确认说明覆盖手改内容。
- 超大预览图：仍受同一识别时限约束，到时失败可重试，不无限等。
- 确认框目标语言只能是 `en` / `es` / `zh`；打开时默认 URL `[lang]`，取消后不记住框内未确认的改动。
- 站点界面语言（URL、工具栏文案、确认框自身文案）不随目标语言下拉变化。
- 失败态下无法改目标语言；若要换语言，须等成功回到就绪后再点（会再弹确认），或刷新页面后重新发起。
- 刷新或离开页面后，上次确认的目标语言丢弃；下一次打开确认仍默认 URL `[lang]`。

## 需求 *(mandatory)*

### 功能需求

- **FR-001**: 系统 MUST 仅在已有图片的控制台编辑页（`/[lang]/console/images/[id]`，且该条为图片而非目录、非新建页）于图片预览与信息表单之间展示一条工具栏。
- **FR-002**: 工具栏最左侧 MUST 提供「AI 识别」操作，使用能表达「AI / 智能识别」含义的图标；图标从项目已有图标库中选取，不新增图标依赖。
- **FR-003**: 进入页面后系统 MUST 检测当前浏览器是否具备本地图像识别能力；不具备则「AI 识别」禁用，悬停提示改用 Chrome 或 Edge 等支持的浏览器。
- **FR-004**: 具备能力且无进行中任务时，「AI 识别」MUST 可点击；点击后 MUST 先弹出确认，不得直接开始识别。
- **FR-005**: 确认文案 MUST 说明：使用浏览器本地能力识别当前图片、成功后将覆盖下方标题与描述、不会自动保存；MUST 同时提供执行与取消；MUST 提供目标语言下拉框，选项与站点支持的 `en` / `es` / `zh` 一致（展示名与站点语言切换器相同），默认值为当前 URL `[lang]`。
- **FR-006**: 用户取消确认后，系统 MUST 关闭确认且 MUST NOT 改表单、MUST NOT 保存。
- **FR-007**: 用户确认执行后，系统 MUST 将按钮切为加载中并禁用点击，直到本次成功、失败或超时。
- **FR-008**: 识别 MUST 针对当前页正在预览的那张图，MUST 在用户本机浏览器内完成，MUST NOT 把图片发到第三方云端识别服务，MUST NOT 为此新增服务端识别接口。
- **FR-009**: 识别成功后，系统 MUST 用结果覆盖表单的标题（Title）与描述（Description），MUST NOT 改其它字段，MUST NOT 自动提交或跳转。
- **FR-010**: 回填所用语言 MUST 为用户在确认框下拉框中选中的目标语言（`en` / `es` / `zh`），MUST NOT 仅绑定页面语言；MUST NOT 因本次选择而改变站点 URL 或界面语言。
- **FR-011**: 标题 MUST 为简短可用标题（建议不超过约 80 个字符，超出则截断并保持语义完整）；描述 MUST 为一段说明画面主体、场景与显著细节的文字。
- **FR-012**: 从确认执行起，系统 MUST 在 30 秒内结束本次识别（成功或失败）。若需先等待本机模型就绪，就绪等待 MUST 不超过 60 秒；超时均视为失败并停止本次识别。
- **FR-013**: 失败或超时后，按钮 MUST 进入失败态；悬停 MUST 显示本次失败原因；表单 MUST 保持识别前的标题与描述（含「标题无效视为整次失败」时不部分写入）。
- **FR-014**: 失败态下再次点击 MUST 立即重试且不再弹确认；重试 MUST 使用上次确认时选中的目标语言；重试期间按钮回到加载中。识别成功回到就绪后再次点击 MUST 重新弹出确认，不得走免确认重试。
- **FR-015**: 加载中 MUST 忽略再次点击，MUST NOT 并行发起第二次识别。
- **FR-016**: 工具栏、按钮状态、确认文案、禁用说明与失败原因 MUST 随当前页面语言提供（项目已支持的语言列表）。
- **FR-017**: 本功能 MUST NOT 改变现有手动保存、取消、删除及其它表单字段的行为。

### 关键实体

- **图片编辑表单**: 当前页已有表单。本功能只读写其中的标题、描述；频道、发布状态等其它字段只读不改。
- **识别结果**: 一次本地识别产出的标题与描述。标题为空或仅空白则整次结果不可用。结果语言等于本次确认的目标语言。
- **识别操作状态**: 按钮的四种对外状态——不支持（禁用）、就绪、进行中、失败。进行中与失败需能让用户区分，失败需能展示最近一次原因。
- **目标语言**: 取值仅 `en` / `es` / `zh`。打开确认时下拉重置为 URL `[lang]`；用户点执行后记住「上次确认语言」，仅供失败重试使用。刷新或换图后丢弃。

## 成功标准 *(mandatory)*

### 可衡量结果

- **SC-001**: 在支持本地识别的环境中，用户从打开编辑页到看到确认，只需一次点击「AI 识别」；确认内语言下拉默认与 URL `[lang]` 一致；取消后 100% 不改表单、不保存。
- **SC-007**: 用户将目标语言改成与页面不同的已支持语言并确认后，成功回填的标题与描述 100% 使用该目标语言，且页面 URL / 界面语言不变。
- **SC-002**: 识别成功后，用户无需再点保存即可在表单中看到新的标题与描述；其它字段与识别前一致；此时尚未写入服务器（刷新后仍为保存前的服务器值）。
- **SC-003**: 在不具备本地识别能力的环境中，100% 的访问会看到禁用的「AI 识别」，悬停可在 2 秒内读到需改用 Chrome 或 Edge 的说明，且不会出现确认或识别过程。
- **SC-004**: 任何一次识别（含大图）都不会无限转圈：确认执行后，用户至多等待就绪时限加识别时限（合计不超过 90 秒）就会看到成功回填或失败态。
- **SC-005**: 失败后用户无需离开页面，一次点击即可重试（无确认框），回填语言与失败前上次确认的目标语言一致；重试前表单保持失败前内容。
- **SC-006**: 使用本功能的用户不会因为识别而误保存或误离开编辑页；保存仍只发生在用户主动点保存之后。

## 假设

- 范围仅限已有图片的控制台编辑页。列表页、公开详情页、频道页、新建上传页、目录均不在本期。
- 本期工具栏只放「AI 识别」一项，最左侧；为以后其它操作留出同一条工具栏，但不实现其它按钮。
- 「浏览器内置 / 本地 AI」指用户当前浏览器提供的设备端图像理解能力，不是项目自建模型，也不是把图传到第三方再识别。图片不离开用户设备用于识别。
- 当前该能力较完整的桌面浏览器主要是 Chrome 与 Edge；其它浏览器按不支持处理。只检测能力本身，不靠浏览器名称白名单决定能否使用（若其它浏览器日后具备同等能力，检测通过则可用）。禁用提示仍点名 Chrome 与 Edge，方便用户知道改用什么。
- 能力检测包括：是否存在可用的本地图像识别接口，以及是否能对当前预览图做多模态理解。仅有文本对话、不能看图，视为不支持。
- 图标从项目已安装的图标包中选一个能表达 AI / 智能识别的现成图标，不为此引入新依赖。
- 确认沿用控制台已有对话框风格（与批量操作确认同类），不用系统原生 `alert`/`confirm`，以便国际化与样式一致。
- 同一张图、当前页未刷新：失败重试不弹确认，沿用上次确认的目标语言。成功后再点会重新确认。换图、刷新或新会话则丢弃上次目标语言。
- 标题约 80 字符、描述一段；不要求结构化标签、不要求一次回填多种语言。
- 下拉选项展示名与站点语言切换器一致：English、Español、简体中文；值为 `en` / `es` / `zh`。站点当前仅这三种语言（以 `src/lib/language.ts` 为准）。
- 打开确认时目标语言每次重置为当前 URL `[lang]`，不记忆上次在框内改过但未确认的选择。
- 超时默认：模型就绪等待 60 秒，识别本身 30 秒。用户未指定精确秒数，取「大图也不至于一直转」的折中。
