# Feature Specification: 图片标签与全屏预览

**Feature Branch**: `013-image-tags-preview`

**Created**: 2026-08-13

**Status**: Draft

**Input**: User description: "在/[lang]/console/images/[id]页面Title和Description表单字段中间增加一个Tags字段（非必填），允许用户为图片填写标签（字符串以英文逗号分隔）。同时将 specs/011-image-ai-recognize 规格中描述的「AI识别」功能进行改造，允许通过AI自动生成图片标签列表（8个标签以内）。实现以上功能意味着需要在图片记录中持久化标签。然后需要在工具栏「AI识别」按钮左侧增加一个「放大预览」按钮图标，点击可以网页全屏预览图片。要实现网页全屏预览，需要支持鼠标缩放或拖动（针对大图）、点击关闭预览等。选择一个社区评价不错、又不那么重型的图片预览方案接入。"

## 用户场景与测试 *(mandatory)*

### 用户故事 1 — 在标题与描述之间填写并保存标签 (Priority: P1)

已登录用户打开某张已有图片的编辑页，在标题（Title）与描述（Description）之间看到一个非必填的「标签」输入框。用户可用英文逗号分隔填写若干标签（例如 `sunset, beach, travel`），保存后再次打开该编辑页，标签仍在。不填标签也可以正常保存。频道、是否发布等其它字段行为不变。

**Why this priority**: 标签是本功能的数据基础。没有可编辑、可保存的标签字段，后续 AI 回填与再次打开回显都无法成立。

**Independent Test**: 打开任一已有图片编辑页，在标题与描述之间找到标签框；填写若干逗号分隔标签并保存；再次进入同一编辑页，确认标签回显且标题、描述、其它字段未受意外影响。另测留空保存，确认仍可成功。

**验收场景**:

1. **Given** 用户打开 `/[lang]/console/images/[id]` 已有图片编辑页（非新建上传页、非目录），**When** 页面加载完成，**Then** 信息表单中标题与描述之间出现「标签」字段，该字段非必填。
2. **Given** 标签框为空，**When** 用户输入以英文逗号分隔的多个标签并保存，**Then** 保存成功；再次打开同一编辑页时，标签按上次保存的内容回显。
3. **Given** 标签框为空且标题已填写，**When** 用户不填标签并保存，**Then** 保存成功，标签保持为空。
4. **Given** 用户输入含首尾空格、连续逗号或空段的字符串（例如 ` a, ,b,c `），**When** 保存，**Then** 空段被丢弃、各标签首尾空白被去掉后持久化；再次打开时不再出现空标签。
5. **Given** 用户正在编辑标签，**When** 查看标题、描述、频道、是否发布，**Then** 这些字段的位置、必填规则与保存/取消/删除行为与改造前一致。

---

### 用户故事 2 — AI 识别同时回填标题、描述与标签 (Priority: P1)

用户在支持本地识别的浏览器中点击「AI 识别」并确认后，系统按确认框所选目标语言生成标题、描述，以及不超过 8 个标签，写入下方表单并覆盖这三项的原值。频道、发布状态等其它字段不变。页面不自动保存、不跳转。确认文案须说明：成功后将覆盖标题、描述与标签，且不会自动保存。失败、超时、不支持、重试规则与既有「AI 识别」一致（见 `specs/011-image-ai-recognize`，并以本规格对回填范围的扩展为准）。

**Why this priority**: 减少手工写标题/描述/标签的成本是识别改造的核心价值；用户必须事先知道标签也会被覆盖。

**Independent Test**: 在支持本地识别的环境中确认执行，验证标题、描述与标签均被新值覆盖，标签个数不超过 8，其它字段不变，且未自动保存。

**验收场景**:

1. **Given** 识别成功并返回标题、描述与标签列表，**When** 识别结束，**Then** 表单标题、描述与标签被新值覆盖（含原先已有内容），标签以英文逗号分隔写入标签框，个数不超过 8，「AI 识别」恢复为可点击的就绪状态。
2. **Given** 识别成功但未给出任何标签（标题有效），**When** 识别结束，**Then** 标题（及有效描述）仍回填；标签框被清空（覆盖为空），不视为整次失败。
3. **Given** 识别成功，**When** 查看表单，**Then** 频道、是否发布等其它字段保持识别前的值；页面不自动保存、不跳转。
4. **Given** 用户在确认框选择了目标语言 L，**When** 识别成功，**Then** 回填的标题、描述与标签均使用语言 L（或其自然变体），即使 L 与当前 URL `[lang]` 不同；站点界面语言不变。
5. **Given** 用户点击「AI 识别」且浏览器支持识别，**When** 确认框出现，**Then** 文案明确说明成功后将覆盖标题、描述与标签，且不会自动保存。
6. **Given** 识别返回超过 8 个标签，**When** 写入表单，**Then** 只保留不超过 8 个标签（按识别结果的先后顺序截取）。
7. **Given** 识别结束但标题为空或仅空白，**When** 处理结果，**Then** 视为整次失败，标题、描述、标签均不部分写入。

### 用户故事 3 — 用工具栏「放大预览」全屏查看当前图 (Priority: P1)

用户在图片预览与表单之间的工具栏上，于「AI 识别」左侧看到「放大预览」操作（图标表达放大 / 全屏查看含义）。点击后，当前图片以网页全屏（遮罩覆盖整个可视区域）方式展示，便于看清细节。大图可用鼠标缩放与拖动查看局部；用户可通过点击关闭控件或点击遮罩空白处关闭预览，回到编辑页，表单内容不变。

**Why this priority**: 编辑页缩略预览尺寸有限，用户在填写标题、描述、标签前需要看清原图；该入口与识别并列，是同一工具栏上的独立能力。

**Independent Test**: 打开任一已有图片编辑页，确认「放大预览」位于「AI 识别」左侧；点击后进入全屏预览；缩放/拖动大图；关闭后回到编辑页且表单未改、未保存。

**验收场景**:

1. **Given** 用户打开已有图片编辑页，**When** 页面加载完成，**Then** 工具栏在图片预览与信息表单之间；「放大预览」位于「AI 识别」左侧。
2. **Given** 当前图片可显示，**When** 用户点击「放大预览」，**Then** 进入网页全屏预览，图片主体可见，编辑页表单被遮罩挡住。
3. **Given** 全屏预览已打开且图片大于可视区域（或用户已放大），**When** 用户使用鼠标滚轮或等价缩放手势，**Then** 图片放大或缩小；拖动时图片跟随移动，便于查看局部。
4. **Given** 全屏预览已打开，**When** 用户点击关闭控件或点击遮罩空白处，**Then** 预览关闭，回到编辑页，标题、描述、标签及其它字段保持打开预览前的值，未发生保存。
5. **Given** 全屏预览已打开，**When** 用户按下 Escape，**Then** 预览关闭，行为与点击关闭一致。
6. **Given** 「AI 识别」处于加载中、失败或不支持，**When** 用户点击「放大预览」，**Then** 仍可打开预览；预览与识别互不阻塞（识别进行中打开预览不中断识别，关闭预览不改变识别状态）。

---

### 用户故事 4 — 既有识别状态机与权限边界保持不变 (Priority: P2)

「AI 识别」的能力检测、确认（含目标语言下拉）、加载、超时、失败悬停原因、失败免确认重试、成功后再点须重新确认等规则保持 011 既有约定。本功能仅把回填范围从「标题 + 描述」扩展为「标题 + 描述 + 标签」，并在工具栏左侧增加预览，不改变登录、所有权与手动保存模型。

**Why this priority**: 避免改造标签时回归既有识别体验；预览是附加能力，不能破坏识别主路径。

**Independent Test**: 按 011 的不支持 / 取消确认 / 失败重试 / 成功后再确认等场景各走一遍，确认行为仍成立，且成功路径额外回填标签。

**验收场景**:

1. **Given** 当前浏览器不具备本地图像识别能力，**When** 页面完成能力检测，**Then** 「AI 识别」禁用并提示改用 Chrome 或 Edge；「放大预览」仍可用。
2. **Given** 用户打开确认后选择取消，**When** 确认关闭，**Then** 标题、描述、标签均保持原值，未保存。
3. **Given** 识别失败或超时，**When** 用户再次点击「AI 识别」，**Then** 不弹确认，沿用上次目标语言立即重试；表单在重试成功前保持失败前内容（含标签）。
4. **Given** 识别已成功、按钮回到就绪，**When** 用户再次点击「AI 识别」，**Then** 重新弹出带语言下拉的确认框。

---

### 边界情况

- 打开的是新建上传页（`/console/images/new`）或目录：本功能的标签字段、放大预览与 AI 回填标签均不出现，行为与现网一致。
- 历史图片尚无标签：编辑页标签框为空；保存时可不填；AI 成功后写入新标签（或清空，若识别未给出标签）。
- 标签仅空白或只有逗号：视为无标签，按空值保存。
- 单个标签过长或标签整体过长：保存时截断或拒绝并提示，避免无法回显的超长串；人工填写不强制「最多 8 个」，8 个上限只约束 AI 回填。
- 用户先手改标签再点识别并确认：按确认说明覆盖手改标签（与标题、描述相同）。
- 图片预览尚未可用：放大预览不可用或打开后说明无法显示；AI 识别仍按 011「无法读取当前图」失败，表单三字段都不改。
- 全屏预览打开时用户刷新或后退：预览结束，不保存草稿；再次进入为服务器上的已保存值。
- 列表页、公开详情页、频道页本期不展示、不编辑、不按标签筛选。
- 本功能不改变现有手动保存、取消、删除及其它表单字段的行为。

## 需求 *(mandatory)*

### 功能需求

- **FR-001**: 系统 MUST 仅在已有图片的控制台编辑页（`/[lang]/console/images/[id]`，且该条为图片而非目录、非新建页）提供本功能。
- **FR-002**: 信息表单 MUST 在标题与描述之间提供非必填的「标签」字段；用户 MUST 能以英文逗号分隔输入多个标签。
- **FR-003**: 系统 MUST 将标签与该图片一并持久保存；再次打开同一编辑页时 MUST 回显上次保存的标签。标签为空时 MUST 仍允许保存。
- **FR-004**: 保存标签前系统 MUST 去掉各标签的首尾空白并丢弃空段；MUST NOT 因标签为空而阻止保存。
- **FR-005**: 「AI 识别」成功后 MUST 用结果覆盖表单的标题、描述与标签；MUST NOT 改其它字段；MUST NOT 自动提交或跳转。
- **FR-006**: AI 回填的标签 MUST 不超过 8 个；超过则按结果顺序截取前 8 个。标签文案 MUST 与本次确认的目标语言一致。
- **FR-007**: 确认文案 MUST 说明：使用浏览器本地能力识别当前图片、成功后将覆盖下方标题、描述与标签、不会自动保存。目标语言下拉、默认值、取消与执行规则 MUST 与 011（并经 012 扩展后的站点语言列表）保持一致。
- **FR-008**: 标题为空或仅空白时，整次识别 MUST 视为失败，MUST NOT 部分写入描述或标签。描述或标签为空但标题有效时，MUST 允许写入（空标签即覆盖为空）。
- **FR-009**: 能力检测、加载中禁用、30 秒识别时限、60 秒就绪等待、失败态悬停原因、失败免确认重试、成功后再点须重新确认、加载中不可并行第二次识别等规则 MUST 继续符合 011。
- **FR-010**: 工具栏 MUST 在「AI 识别」左侧提供「放大预览」操作，使用能表达放大 / 全屏查看含义的图标；图标从项目已有图标库中选取。
- **FR-011**: 用户点击「放大预览」后，系统 MUST 以网页全屏（遮罩覆盖可视区域）展示当前编辑页正在预览的那张图。
- **FR-012**: 全屏预览 MUST 支持鼠标滚轮（或等价手势）缩放，以及在放大后拖动查看局部；MUST 提供关闭控件，MUST 支持点击遮罩空白处关闭，MUST 支持 Escape 关闭。
- **FR-013**: 关闭预览后系统 MUST 回到编辑页，MUST NOT 改表单、MUST NOT 保存。
- **FR-014**: 「放大预览」MUST 不依赖本地识别能力；识别处于任何状态时预览 MUST 仍可开关，且 MUST NOT 中断或重置识别。
- **FR-015**: 工具栏、标签字段标签名、确认文案（含覆盖标签的说明）、预览按钮无障碍名称与关闭预览文案 MUST 随当前页面语言提供（项目已支持的语言列表）。
- **FR-016**: 本功能 MUST NOT 改变现有手动保存、取消、删除及其它表单字段的行为；MUST NOT 在列表页、公开页或频道页引入标签展示或筛选。
- **FR-017**: 识别 MUST 仍在用户本机浏览器内完成，MUST NOT 把图片发到第三方云端识别服务。全屏预览 MUST 使用当前页已可访问的图片，MUST NOT 为此把原图发到第三方托管。

### 关键实体

- **图片编辑表单**: 现有编辑页表单。本功能在标题与描述之间增加可选标签；AI 识别读写标题、描述与标签；频道、发布状态等其它字段只读不改。
- **图片标签**: 归属单张图片的可选短词列表，编辑与展示时表现为英文逗号分隔的字符串。AI 一次最多写入 8 个；人工填写不强制该上限。随图片持久保存。
- **识别结果**: 一次本地识别产出的标题、描述与标签列表。标题为空或仅空白则整次结果不可用。结果语言等于本次确认的目标语言。
- **识别操作状态**: 沿用 011 的四种对外状态——不支持、就绪、进行中、失败。
- **全屏预览会话**: 用户从工具栏打开、在当前页覆盖层中查看单张图的临时会话。关闭后不留持久状态，不影响表单与识别状态。

## 成功标准 *(mandatory)*

### 可衡量结果

- **SC-001**: 用户在编辑页填写标签并保存后，100% 能在再次打开同一编辑页时看到所保存的标签；不填标签时保存成功率与改造前仅填标题保存一致。
- **SC-002**: 在支持本地识别的环境中，用户确认执行一次识别后，无需再点保存即可在表单中看到新的标题、描述以及不超过 8 个标签；其它字段与识别前一致；刷新后仍为保存前的服务器值。
- **SC-003**: 确认框在 100% 的可点击「AI 识别」路径上说明将覆盖标题、描述与标签；取消后 100% 不改这三项、不保存。
- **SC-004**: 用户从打开编辑页到进入全屏预览只需一次点击「放大预览」；从预览回到编辑页（关闭控件、点遮罩或 Escape）不超过一次明确操作；关闭后表单 100% 保持预览前内容。
- **SC-005**: 对超出可视区域的大图，用户能在预览中通过缩放与拖动看清局部，而无需离开编辑页另开新标签下载原图。
- **SC-006**: 不具备本地识别能力时，100% 的访问仍可使用「放大预览」，且「AI 识别」保持禁用与既有引导。
- **SC-007**: 使用本功能的用户不会因为识别或预览而误保存或误离开编辑页；保存仍只发生在用户主动点保存之后。

## 假设

- 范围仅限已有图片的控制台编辑页。列表页、公开详情页、频道页、新建上传页、目录均不在本期；不按标签搜索或筛选。
- 本规格扩展并在冲突处覆盖 `specs/011-image-ai-recognize`：回填范围增加标签；确认文案增加「将覆盖标签」；工具栏最左侧改为「放大预览」，其右侧仍为「AI 识别」。011 中「本期工具栏只放 AI 识别一项」「不要求结构化标签」的假设不再适用。
- 目标语言选项与默认值遵循 012 之后的站点语言列表（英 / 西 / 法 / 日 / 简中 / 繁中），不再沿用 011 原文中仅三种语言的表述。
- 标签覆盖策略与标题、描述相同：确认执行即整表覆盖，含覆盖为空。用户若只想改标签、不想被动覆盖，应先保存或避免在有手改草稿时确认识别。
- 8 个上限只约束 AI 回填，不拦截人工输入更多标签。规划阶段可为超长字符串设定与现有标题/描述同类的长度保护，但不另做标签词库或自动补全。
- 标签不做大小写合并或同义词归并；去空白与去空段即可。
- 「放大预览」只预览当前编辑的这一张图，不做相册上一张/下一张。点击页面上方缩略图本身不要求打开全屏（入口以工具栏按钮为准）。
- 全屏预览采用社区评价较好、体积较轻的现成预览能力，避免自研一套缩放/拖动/关闭逻辑，也避免引入功能远超单图预览的重型画廊套件。具体选型在规划阶段确定。
- 预览图标从项目已安装的图标包中选取，不为此单独引入新图标库。
- 不自动保存：与现网「用户点保存才提交并回列表」一致。
- 不新增服务端识别、不改图片文件存储与权限模型。编辑页原有登录与所有权校验保持不变。
- 超时、重试、不支持提示等未在本规格重述的识别细节，全部继承 011。
